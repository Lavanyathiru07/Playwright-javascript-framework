What is async?
The async keyword is used to declare a function that performs asynchronous operations and allows the use of await inside it.

What is await?
The await keyword pauses function execution until an asynchronous operation completes and returns its result.

Why do we use await in Playwright?
Because browser actions and API calls take time to complete. Await ensures the operation finishes before moving to the next line of code.
